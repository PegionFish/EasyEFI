## 已知限制（设计决策与约定）

1. **core 不依赖 S08 控件**：菜单/确认/帮助/错误页渲染在 core 内（编号/架构灰显/danger 标记/desc 展开属业务语义，TuiWidget 契约明确不管业务）。缩短关键路径；S12/S13 仍可用控件。
2. **core 借用 CONFIG**：glue 持有 ConfigFree/ConfigFreeErrors 生命周期；Reload 回调内 glue 原地更新 LAUNCHER_SESSION。core 不链接 S03 符号 → 宿主测试直接构造 CONFIG 夹具。T11-5 的"坏 JSON"在 core 层以 cfg=NULL+Banner 覆盖；真实 JSON 解析链路由 S03/T03 + 冒烟覆盖。
3. **ExecOps 路径约定（已对齐 S10 实际实现）**：ExecEfi = 活 Fs + 根相对路径（S10 RootRel 只去前导斜杠，不剥 fsN: 前缀）；ExecNsh ShellFullPath = 启动卷根相对、ScriptFullPath = fsN: 全限定（含 ':' 强制）。auto: 候选 FullPath = 根相对反斜杠形式（S10 约定 4），Fs 经 AutoVol 回调解析活卷。
4. auto: 多命中 → CANDIDATES 选择态（Display 展示，options 保留）；单命中直接执行；零命中 → 错误页。
5. boot:XXXX → 直接 ExecBootNext（§5.6 无确认要求）；reset 动作与内置 Reboot → 强制 CONFIRM 默认 N；danger/confirm 标志 → CONFIRM。
6. 数字直选 1-9（单位）；导航端点钳制不环绕、跳过灰显；PgUp/PgDn 按视口行数。>9 条目用方向键。
7. options UTF-8→UCS-2 为 core 内静态严格解码器（非法字节/星面 → '?'；避免跨流依赖 Utf8Lib——集成后可选切换）。
8. `LAUNCHER_CONFIG_MAX_BYTES=65536` 模块常量（建议 PCD 化，见超范围建议）。
9. Count==0（无有效条目）→ 内置菜单 + 横幅（S03 交接约定）。
10. 无 Shell 协议（固件直启）→ 映射名空 → .nsh/fsN: 执行报错页降级；apps 经 BootFs 仍可 exec；菜单/Shell 退出仍可用；EASYEFI_RAN 仅在 Shell 可用时置（§3.4 语义）。ArmVirtQemu 无 SecureBoot 变量 → 状态栏 SB:? 属预期。
11. 倒计时由 glue 驱动（10×100ms PollKey+Stall=1s/Tick，无定时器事件——满足 S10 已知限制 1"调用方自停定时器"，本流无事件可停）；core Tick 纯逻辑可测。skip_timeout 生效值 glue 计算（cfg?cfg->SkipTimeout:PcdSkipTimeoutDefault）。
12. DEGRADED 且配置有效时：菜单=配置项（data: 灰显）+系统项；discovery 行仅在 cfg=NULL 时添加（配置自带 auto: 项即§5.2"auto: 外部介质条目"）。

## 集成注意事项（给 leader）

1. **[已解决] ntfs nsh 递归**：曾阻塞于 main 上 S10 接管旧版缺 argv[0] 修复；S10 最终版（fc86913/e57448b）合入后六场景全 PASS。集成发现 B1 已固化。
2. **[已解决] exec 后池损坏**：根因 = 我的 MapName 曾 FreePool GetMapFromDevicePath 返回串（该串挂 Shell 延迟释放链表，集成发现 A8，S12 独立发现）。二分矩阵（A 仅 ESC/C 直跑 stub/G 双 stub 均干净，B Launcher+ExecEfi 损坏）定位到 exec 路径后与 A8 互证。修复：不 FreePool。修复后 fat/ntfs 双架构干净退出（收尾标记实证）。
3. **[已解决] S09 GUID 漏列 / 候选 Fs 悬空**：A9（S09 .inf 补 [Guids]）+ A7（332553a 所有权裁决：Fs 按卷缓存稳定、VolFree 不销毁、借用不 Destroy）均已合入；我移除临时 GUID 声明与 P3Fs Destroy，AutoVol/FsByIndex 回调保留（防御 + FsName 供给）。
4. **S06 渲染假设**：core 每状态 TuiClear+全量绘制+TuiFlush；同属性连续文本一次 TuiPutText（serial 可 grep 整行标记）。冒烟断言依赖 ConOut 含 serial（S00 已实证）。C1/C2（OVMF 宽度虚高/右下角滚动）由 S06 内部处理，core 按 TuiGetSize 布局无硬编码。
5. **冒烟执行目标 = 专用 S11Target**（smoke/Target/，本碎片 [Components] 接入，标记 `[S11-TARGET] ran <arch>`）——不依赖 FM/Editor stub，S12/S13 真实应用合入后仍稳定。S18 若不需要可整体移除（不影响 Launcher 本体）。
6. **S09 语义依赖**：VolFindP3 失败→DEGRADED（不挂死）；VolEnumerate 的 Dp 用于映射名与启动 ESP 匹配（DpEqual 忽略 END）；glue 保留 Vols 至退出（VolFree 收尾），Fs 均借用（缓存会话级）。
7. 宿主测试复跑：`make -C EasyEfiPkg/Application/Launcher -f host.mk test`（fuzz 种子 0x11A0BEEF 固定）。
8. module.dsc.inc 含 Launcher + S11Target 两个 [Components]；DSC 聚合已 !include。
9. **EASYEFI_RAN**：任何正常退出路径（含 TuiInit 失败/CoreNew 失败）先置 yes（Shell 可用时）——兼容布局架构探测依赖（§3.4）；冒烟未直接断言该变量（S15 已实证机制），S18 整矩阵可补。
