## 契约变更提案（§4 流程，**已获批落地**，存档）

**问题**：`TuiTheme.h` 冻结常量 `TUI_ATTR_SELECTED = (TUI_FG_BLACK | TUI_BG(TUI_FG_LIGHTCYAN))` = 0x00 | (0x0B<<4) = **0xB0**。UEFI SimpleTextOut 属性仅 bit0-3 前景 + bit4-6 背景（背景只有 0-7，**不存在亮色背景**）；edk2 三层控制台一致校验 `(Attribute | 0x7F) != 0x7F → EFI_UNSUPPORTED`（ConSplitter.c:4714、TerminalConOut.c:584、GraphicsConsole.c:1349，edk2-stable202608 实证）。0xB0 含 bit7 → SetAttribute 被拒 → S06 OutputRun 提前退出 → **选中行整段不输出（双架构实证）**。宿主 MockTui/MockConOut 不校验属性值 → 宿主测试全绿未暴露。

**提案 diff**（TuiTheme.h，leader 独占）：
```c
-#define TUI_ATTR_SELECTED   (TUI_FG_BLACK     | TUI_BG(TUI_FG_LIGHTCYAN))
+#define TUI_ATTR_SELECTED   (TUI_FG_BLACK     | TUI_BG(TUI_FG_CYAN))
```
0xB0 → 0x30（黑字青底，经典选中外观；UEFI 文本模式无亮背景，CYAN 是最接近 LIGHTCYAN 的合法值）。其余主题常量均 ≤0x7F 合法（已逐一核对：NORMAL 0x07/DANGER 0x0C/DISABLED 0x08/NONASCII 0x0E/STATUSBAR 0x70/BANNER_ERR 0x4F/TITLE 0x0B/KEYBAR 0x70）。

**影响流**：S00（MockTui 建议加属性合法性校验）、S06（MockConOut 同建议；真实后端无需改）、S08（本流）、S11/S12/S13（选中高亮消费方，修复后自动受益）。

**定位证据链**（9 轮探针）：
1. 直调 gST->ConOut->SetAttribute(0x30)/OutputString → Success 且渲染；
2. S06 单格/60 格长段/横幅后/横幅+长段分次 flush（0x30 探针）→ 全 Success；
3. DrawFrame 单次 flush（契约 SELECTED）→ Unsupported，SELECTED 段光标定位后无 SGR 无文本；
4. TuiScreenPeekCell(2,2) → **attr=0xB0**（缓冲值即契约常量，控件写入无误）；
5. 绕过 S06 按首帧脏段精确复现完整 flush 调用序（26 步，SELECTED 用 0x30）→ **全 Success，"1. alpha" 完整渲染**；
6. edk2 源码三层 SetAttribute 校验式一致拒绝 >0x7F。
结论：固件/ConSplitter/S06/控件逻辑均正常；唯一非法输入是契约常量 0xB0。

## 已知限制

行为约定（契约未明说处的裁决，均写入代码注释）：
1. **ListHandleKey 返回码语义**：导航/数字直选消费 → EFI_SUCCESS；ENTER/ESC/F 键/非数字字符 → EFI_NOT_READY（调用方分发业务动作）；空表全不消费。控件无业务语义（不知"危险/固件"，只认 attr/disabled）。
2. 列表编号 = 绝对序号 index+1，右对齐宽 = Count 位数 + ". "；'1'-'9' 直选第 1-9 项，'0' 直选第 10 项；disabled/越界忽略。上下/翻页首尾钳制不回绕；PGUP/PGDN 移动 VisibleRows 后沿运动方向找最近非 disabled，找不到保持原选中。
3. 属性覆盖序：Disabled → ATTR_DISABLED；Selected → ATTR_SELECTED；其余条目基础 Attr。
4. ListSetItems 深拷贝文本、事务式（OOM 回滚保旧表）；NULL 条目文本按空串；ListNew(0) 钳制为 1 行视口。
5. **DialogConfirm**：Y/y/N/n 直答；Enter=DefaultYes；ESC → *Yes=FALSE + **EFI_ABORTED**；其它键忽略；TuiWaitKey 错误原样传播（*Yes 保持入口置 FALSE）。调用方继续的条件 = !EFI_ERROR && *Yes。**对话框关闭后调用方负责重绘底屏**（TuiScreen 契约无保存/恢复 API；冒烟应用演示了该约定）。正文单行截断；框宽自适应（≥20）钳制到屏宽，居中。
6. **InputHandleKey**：契约无输入行绘制面 → 拒绝信号走返回码：非 ASCII/控制字符 = **EFI_UNSUPPORTED**（AsciiOnly 时 >0x7E 拒；控制字符任何模式拒），容量满 = **EFI_BAD_BUFFER_SIZE**；调用方据返回码渲染闪烁提示。支持光标编辑（左右/Home/End/前向删除）；Enter → InputDone；ESC/TAB/F 键不消费；Done 后不消费。InputNew(0) 合法（不可输入字符）。
7. BannerDraw 全宽指定 attr；KeybarDraw 底行固定 TUI_ATTR_KEYBAR；BoxDraw 纯 ASCII +-|，标题段 " Title " TITLE 属性（预算 W-6），W<2/H<2 no-op。
8. 屏幕尺寸经 TuiGetSize，失败保底 80×25；所有绘制经 TuiScreen 契约（越界钳制是屏幕层职责）。
9. 内存全走 MemAlloc/MemFree（canary 后端配对验证）；ListFree/InputFree NULL 安全。
10. **S06 滚动安全限制兼容**：右下角格 (Rows-1,Cols-1) 由 S06 Flush 永不输出（ConOut 固有滚动风险）；本流控件布局不依赖该格（键位条/横幅文本左对齐，该格仅为填充空格），无需特殊处理，实机渲染无滚动损坏（双架构冒烟实证）。
