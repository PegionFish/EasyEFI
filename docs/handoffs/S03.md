## 契约符合性（无变更 / 变更提案编号）

**零擅改**。 Include/Contract/** 未动；config/launcher.example.json 只读。

- **已批准并采纳的契约变更**：DOM 助手 `JsonArrayCount` → `JsonDomArrayCount`（S03 上报与 JsonLib.h 同名冲突，leader 批准改名并合入 main；本流已全面采纳，include 期改名 workaround 已移除）。
- **契约观察①（浮点/DOM 表达力，待 leader 裁决，不阻塞）**：DOM 数值仅 INT64 无 REAL 类型，而 jansson 实际解析浮点为 JSON_REAL（design F22 "JsonLib 无浮点" 前提与源码不符）。处置：**双适配器在边界拒绝 real → EFI_INVALID_PARAMETER**（保持同构；Launcher 侧=解析失败→内置菜单+错误横幅，正是 §5.3 语义）。后果：`CFG_ERR_FLOAT` 经适配器不可达，T03-6 断言适配器拒绝。若需核心级 CFG_ERR_FLOAT+ItemIndex，提案：DOM 增 `JSON_REAL`（union +double）——走 §4，本流不擅自实现。
- **契约观察②（jansson 枚举同名）**：jansson 公开枚举 JSON_OBJECT/ARRAY/STRING/NULL 与 DOM JSON_TYPE 同名；仅宿主适配器 TU 受影响，已在 JsonDomHost.c 内 include 期宏改名解决（UEFI 侧 JsonLib 类型不透明，无此问题）。无需契约动作。
- **语义约定（契约未细化处，本流定义并实证）**：
  1. `ConfigValidate` 返回 EFI_SUCCESS = 产出尽力而为 CONFIG（调用方查 ErrCount 决定横幅/帮助页）；根非 object/参数非法/OOM → 错误且 *Out=NULL。
  2. 警告码：契约枚举无警告专用码 → 未知字段警告 Code=0；skip_timeout 钳制警告复用 CFG_ERR_RANGE。
  3. title/version 可选（缺省空串）；items 必填非空数组（空→MISSING_FIELD）；id 必填且非空；arch 缺省=双架构，空数组=掩码 0。
  4. ASCII = 可打印 0x20..0x7E（控制字符亦拒）；options 例外允许 UTF-8（§6 明示 UTF-8→UCS-2）；path 不做 ASCII 检查（委托 PathParse，S04 拒控制字符/非法 UTF-8）。
  5. 每项 first-error-wins（一条错误即跳过该项）；未知字段警告对非法项照收。
  6. danger=true 隐含 Confirm=TRUE；shell/reset 的 path、非 exec 的 options → 警告忽略。
  7. CONFIG_ITEM.Path 存原始输入串（含反斜杠）；消费方运行时经 PathParse 取规范化 Rel。
  8. path 错误映射与 S04 裁决对齐（leader 指示后细分）：存储字节帽 >255 → CFG_ERR_TOO_LONG；PathParse EFI_BAD_BUFFER_SIZE → CFG_ERR_TOO_LONG（防御分支，字节帽先触发故经核心不可达）；其余文法非法（含非法 UTF-8/星面/控制字符/穿越/坏前缀）→ CFG_ERR_BAD_PATH。更细的 CFG_ERR 枚举码需契约变更（§4），未擅自添加。

## 已知限制

1. 浮点 anywhere（含未知字段）→ 整份文档适配器拒绝（与"JsonLib 无浮点"设计前提一致；见观察①）。
2. 对象键 >63 字节截断至 63（DOM Key[64]；schema 键均短，仅影响未知字段告警显示）。
3. DOM 转换/dumps 深度上限 64（配置实际 ≤4；防御恶意深嵌套耗尽 UEFI 栈；jansson 自身解析上限 2048）。
4. 标量根（"str"/5）适配器拒绝（与 JsonLoadString 无 DECODE_ANY 行为对齐）；数组根接受→核心 ROOT_TYPE。
5. 宿主 jansson 依赖共享 edk2 子模块源码路径（`JANSSON_SRC` 可覆盖）；brew 路线不可用（install 超时无输出）。
6. 冒烟镜像 JSON 注入用 mtools 偏移 loop（mktestimage fat 变体无数据注入口；ntfs 变体才有 --data-dir）。
7. 非 BMP 码点（4 字节 UTF-8）在 path 中被 S04 拒绝（UCS-2 契约）；name/desc 本就 ASCII 纪律。
