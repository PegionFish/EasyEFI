## 已知限制

键位（design §7.3 功能集的实现映射；§5.5 未规定 Editor 具体键位）：
- 编辑态：可打印字符插入 / Enter 换行 / Backspace / Delete / 方向 / PgUp / PgDn / Home / End /
  **F2 保存**（无文件→另存为）/ **F3 查找输入**（needle 保留，ENTER=执行并跳光标后首个命中=下一）/
  **F4 上一命中** / **F5 另存为**（预填当前路径，AsciiOnly）/ **F6 跳行** / **F7 撤销** / **F10|ESC 退出**。
- 查找输入态：TAB=大小写开关（仅 ASCII 折叠，模型语义）；ESC 取消。跳行态：仅数字。
- 修改退出三键：**S=保存并退出 D=放弃 ESC=取消**（未修改直接退出）。
- 错误页：任意键；致命（打开失败/超限）→ exit=1，非致命（保存失败）→ 回编辑。

语义决定：
1. **保存非原子**：三后端 Open 均不截断且契约无 Truncate → Info 拒目录 → Delete → Create → Write → Flush → Close。
   Delete 后 Write 前失败会丢原文件（MVP 接受；原子化见超范围建议）。
2. **SaveFailed 标志**：ModelSave 即移动模型保存点；磁盘写失败时 core 置 SaveFailed，
   显示 Modified = ModelModified || SaveFailed，直到下次成功保存/打开（保守，宁多提示不漏提示）。
3. 查找命中缓存于任何编辑/撤销后失效（需重新 F3）；命中允许回绕；空 needle → 提示不执行。
4. 光标=反显单元格（TUI_ATTR_SELECTED；契约无光标定位 API）；垂直移动无目标列记忆（模型语义）。
5. 状态栏：basename(≤16)+*+L:C(1 基)+UTF-8+BOM(有时)+光标 U+XXXX(非 ASCII CP)/RAW:0xXX(非法字节)；
   行尾插入位无 token 不显示码点。输入行 needle 仅 UCS-2（ConIn 限制，非 BMP 不可输入）。
6. 退出码：0 正常 → EFI_SUCCESS；1 致命 → EFI_LOAD_ERROR。正常退出置 EASYEFI_RAN=yes（Shell 可用时）。
7. T13-12 以 MockFs 非空目录为目标模拟保存失败（MockFs 无权限语义）；真实只读目录覆盖待 S09 POSIX 后端集成补测。
8. 未命名新文件：状态栏 `<new>`；F2/确认 S → 另存为输入。
