## 集成注意（S18）
- staging 组装：P1/P2 = Shell{Arch} + boot/startup.nsh（两份）+ ntfs.efi（S14 产物）+ Launcher/FileManager/Editor + Tools（用户 drop-in 位）；P3 = launcher.json + scripts/ + entries/ + payloads/ + docs/。
- 当前整镜像证据用 stub Launcher；真实 Launcher/FM/Editor 合并后重跑 T16-6 + V-08 刷机闭环。
- mkfs.vfat 对 loop 设备报 CHS 几何警告（Windows 启动相关）——UEFI 引导不受影响（GPT+fallback），可忽略。
- Windows 写盘指引（用户文档素材）：Rufus DD 模式或 balenaEtcher 写 .img；写后若 U 盘大于镜像，Linux 下 fix-gpt.sh /dev/sdX --grow（Windows 下可用 DiskGenius 扩容 NTFS 分区或忽略——P3 容量小于盘容量不影响使用，备份头错位 Windows 可能提示修复）。
- 实盘 dd 命令与警告见 design §8。
