## 契约符合性（无变更 / 变更提案编号）

**契约零变更**——仅消费 TuiScreen/TuiInput/TuiTheme/FsOps/ExecOps/VolumeModel/EfiMem。模块级语义决策（非契约变更，记录备查）：

- 过滤/命令键消歧：'/' 显式进入过滤或首个可打印字符启动；过滤激活后所有可打印字符（含 v/s/r）追加；未激活时 v/s/r=卷列表/搜索/刷新命令。ESC 先清过滤再上级。
- 确认框 ENTER 视为取消（默认 N 防误刷）；Y 执行，N/ESC 取消。
- 搜索仅文件名子串（大小写不敏感）、仅文件（不含目录名）、深度 ≤32、命中 ≤256。
- 预览二进制判定=含 NUL 字节；文本非 ASCII → '?' 占位（ConOut 无 CJK，design F04）。
- 复制覆盖=先 Delete 后 CREATE（UEFI SimpleFileSystem 不截断已存在文件；宿主 T12-7 实证 13→5B）。

1. 结构上限为模块常量（MVP）：FM_MAX_PATH 512 / FM_MAX_NAME 128 / FM_MAX_FILTER 128 / FM_MAX_RESULTS 256 / 搜索深度 32；超限截断/停止（建议节有 PCD 化提议）。
