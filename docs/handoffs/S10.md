## 契约符合性

**Include/Contract/ 零变更**（ExecOps.h/ExecPath.h/VolumeModel.h/FsOps.h 未触碰）。
契约未明说处的实现解释（非变更提案，签名/语义均按契约文字落地）：

1. **ExecEfi FullPath** = 卷根相对文件路径（前导 '/'/'\\' 均可，内部规范化）；Fs 指定卷。
   卷设备路径经 `VolEnumerate` 输出中 `Vols[i].Fs == Fs` 指针匹配取得（VOLUME_INFO 是契约内
   唯一 Fs↔Dp 关联面）；匹配失败兜底 = 全系统唯一含该文件的卷，多命中 fail-closed（EFI_NOT_FOUND）。
2. **ExecNsh ShellFullPath** = 启动 ESP 根相对路径（"本 ESP 的 Shell.efi"，glue 取自身
   LoadedImage 来源卷 Dp 拼接）；**ScriptFullPath** = 运行时全限定路径（须含 ':'，fsN: 形式，
   调用方解析；含双引号拒绝）。
3. **LoadOptions 完整构造** = `L"Shell.efi " + ["]<script>["] + [ args]`（UCS-2 含 NUL）。
   argv[0] 令牌为必要实现细节（见集成注记 ①）；契约公式描述的是脚本/参数载荷。
4. **EXEC_CANDIDATE.FullPath** = 卷根相对全路径（前导 '\\'，与 Fs 配对唯一确定文件）；
   Display = 卷标签 + ": " + 同路径。fsN: 前缀属 Shell 概念，由调用方 glue 按需添加。
5. **返回值通道**：ExecEfi 返回值与 *ImageReturn 同为 StartImage 状态（UEFI 语义：StartImage
   返回值即目标 Exit 码，机械失败与目标错误码同通道，已核实 CoreStartImage）；LoadImage 失败时
   两者均为加载错误。ExecNsh 返回 StartImage 状态（嵌套 Shell 退出码）。
6. **ExecFreeCandidates**：单块 MemAlloc，MemFree 一次；Fs 借用不释放。

## 已知限制

1. **EventsClose 只覆盖本库自身创建的事件**（MVP 为空注册表+真实关闭循环）。UEFI 无事件枚举
   API，库无法关闭调用方的事件 → **调用方应用自己的定时器须在调 ExecEfi/ExecNsh 前自行停止**
   （S11 倒计时定时器，见集成注记 ②）。T10-4 断言的是核心调用序列（缝级）。
2. ConOut 恢复 = 模式号保存/恢复（SetMode 清屏，调用方 TUI 重绘）；不保存光标位置/属性。
3. ExecEfi 面向应用镜像：LoadOptions 缓冲在 StartImage 返回后释放（Shell 启动时自行拷贝，
   已核实）；若目标是常驻驱动且延迟引用 LoadOptions 会悬空——MVP 范围外（exec 语义=应用）。
4. auto: 候选顺序 = VolEnumerate 枚举序（排序权威在 S09）；候选 Fs 借用存活依赖 S09 缓存语义。
5. 冒烟用 S05/S09 契约替身（worktree stub 未定义契约符号）；真实库集成后换 Smoke.dsc 解析即可
   （fixture 仅定义 S10 引用符号，真实库是超集，无冲突）。
6. 目标 ExitBootServices 则一去不返（预期，设计 §5.6）；ImageReturn 不写入。

## 集成注意事项（给 leader）

① **S11/S15 必读 —— ExecNsh argv[0] 令牌**（QEMU 实证 + 源码核实，已单独发消息）：
   Shell.c ProcessCommandLine 对非选项参数 `if (LoopVar == 0) continue;`（注释 "First argument
   should be Shell.efi image name"）→ file-name 必须落在 Argv[1+]。EfiShellExecute 启动嵌套
   Shell 自己前置 `L"Shell.efi -exit "`。缺 argv[0] → FileName 不解析 → 隐式 -nostartup 不生效
   → startup.nsh 重跑 → 无限递归 → 栈耗尽 data abort（aa64 首跑崩溃根因，修复后标记恰好 1 次）。
   建议 design.md D9 公式补注 argv[0]（leader 独占文档，由你裁决）。S15 父 Shell 由固件 BmBoot
   启动，OptionalData 约定不同，不受影响。
② **S11**：调 ExecEfi/ExecNsh 前停掉自己的倒计时定时器（库无法代劳，见已知限制 1）；
   ScriptFullPath 经 Shell 协议 `GetMapFromDevicePath` 解析运行时 fsN —— **返回值是 ';' 分隔的
   多别名**（如 `FS0:;HD0a0b:;BLK1:`，已核实 ShellProtocol.c），取首段 FS 名；
   ShellFullPath 传启动 ESP 根相对 Shell 路径（如 `\EFI\BOOT\BOOTX64.EFI`）。
③ **S09**：a) FS_OPS 实例须按卷缓存、跨 VolEnumerate/VolFindP3 调用指针稳定（ExecEfi 指针匹配

   b) VolFree 只释放 VOLUME_INFO/Dp，**不得销毁 Fs 实例**（候选列表存活期间借用有效）；
   c) UEFI 后端 Info/Open 须接受无前导斜杠的根相对路径（我的核心统一规范化为该形式查询，
   与 S00 MockFs 约定一致；SFS Root->Open 需前导 '\\' 由后端补）。
