## 已知限制

契约未细化处的实现决定（均已测试固化）：
1. **光标**：行/列 0 基，列=token 索引（可等于行长=行尾插入位）；`ModelGotoLine` 1 基。越界一律钳制不报错。垂直移动列钳制到目标行长，**无目标列记忆**（回移不恢复原列）。
2. **行尾**：仅 LF/CRLF 作终止符；**孤立 CR 按内容 token 保留**（不作行终止符，往返不变）。主约定=CRLF 数>LF 数→CRLF，否则 LF（平票/无终止符→LF）。
3. **限额**：MaxBytes 同时约束加载与编辑增长（插入/换行超限 EFI_BAD_BUFFER_SIZE，状态不变）；`ModelNew(0, …)`=不限。`MODEL_INFO.ByteSize`=加载时字节数（契约注释语义），不随编辑变化。
4. **撤销**：`UndoDepth=0`=禁用撤销（Modified 跟踪仍有效）；空栈撤销返回 EFI_NOT_FOUND；无 redo（契约未定义）。连续插入合并条件=中间无任何其它操作（含光标移动/保存）且光标紧接上次插入末尾。
5. **插入**：CP 经 Utf8Encode→Utf8Decode 落地为 token（编码策略委托 Utf8Lib）；非法码点（代理区/超 U+10FFFF）→ EFI_INVALID_PARAMETER，模型不改动。光标前进=解码出的 token 数。
6. **查找**：token 级 CP 子串；RAW 不透明字节不参与匹配；大小写开关**仅折叠 ASCII**；空 needle→0 命中（EFI_SUCCESS）；允许重叠命中；命中按行/列升序。
7. **渲染**：1 token=1 格（宽度恒 1）；ASCII→原字符+TUI_ATTR_NORMAL；非 ASCII CP/RAW→TUI_NONASCII_CHAR+TUI_ATTR_NONASCII；行尾后空格填充；越界行/NULL Out→EFI_INVALID_PARAMETER，Width 0 合法。
8. **空操作边界**（文件头退格/文件尾前删等）返回 EFI_SUCCESS 不产生撤销步。
9. 内存只用 MemAlloc/MemFree（不用 MemRealloc，见集成注记）；无 libc 依赖（自写 CopyBytes/MoveBytes），宿主/UEFI 单一路径。
10. **ModelTokenAt**（获批新增）：行/列越界→EFI_NOT_FOUND，**列=行长（行尾插入位）亦 NOT_FOUND**（该处无 token）；NULL 参数→EFI_INVALID_PARAMETER；成功时按值拷贝 token（CP 或 RAW）。
